# Game Brief: Night Shift <<

**One-sentence pitch:** CPU 안에서 야간 근무하는 작은 로봇이 비트 줄을 `<<` `>>`로 밀어 발판을 옮기고 출구까지 길을 만드는 퍼즐 게임.

## Core loop
- 보드의 비트 줄(1 = 발판, 0 = 빈칸)을 보고 길을 계산한다.
- 로봇을 걷게 하고(좌우·아래), 줄을 한 칸씩 밀어(`<<` `>>`) 발판을 옮긴다.
- 시프트 횟수 제한 안에 출구에 도달하면 클리어, 실수하면 되돌리기·재시작으로 다시 푼다.

## Player goal & fail state — what "working" looks like
- 목표: 시프트 횟수 제한 안에 출구 칸에 도달한다. 스테이지 5개를 설명 없이 순서대로 풀 수 있어야 한다.
- 실패: 로봇이 줄 끝 밖으로 밀려나 추락하면 즉시 재시작. 횟수를 다 쓰고도 출구에 못 가면 되돌리기 또는 재시작.

## MVP — what must exist to be the game
- 8칸 줄 2~3개를 그리는 보드와 줄별 10진수 표시
- 좌우 시프트와 끝에서의 비트 소실
- 로봇 걷기·내려가기, 줄과 함께 밀리기, 추락 판정
- 시프트 횟수 제한과 남은 횟수 표시
- 되돌리기(Undo)와 재시작
- 출구 도달 판정과 스테이지 5개 순차 진행 (`StageData`)
- itch.io용 WebGL 빌드 확인

## Out of scope — not building this
- 로테이트, 캐리, 산술 시프트, 마스크 (프로토타입 판단 이후 월드 2~4)
- 그래픽, 애니메이션, 사운드 (도형만 사용)
- 스토리(근무 일지), 타이틀·메뉴, 별 평가, 저장
- 레벨 에디터 (인스펙터에서 문자열로 입력)

## Build order
1. `BoardLogic`(순수 C#): 상태 구조, 시프트·소실 로직 (11/5)
2. `BoardView`, 로봇 걷기·내려가기, 줄과 함께 밀리기, 추락 (11/6)
3. 횟수 제한, 되돌리기, 재시작, 출구 판정, `StageData` (11/7)
4. 스테이지 5개 입력과 해답 검증, WebGL 테스트 빌드 (11/8)
5. 11/9 플레이 테스트로 진행 여부 판단

**Who it's for / what they feel:** 논리 퍼즐을 좋아하는 플레이어가 "아, 그렇게 푸는구나" 하는 깨달음을 느끼는 짧은 퍼즐.

**Art & audio direction:** 프로토타입은 단색 도형만 쓴다. 이후 터미널·회로 느낌의 단순한 픽셀 톤으로 확장.

**Reference game:** Baba Is You 류의 규칙 조작 퍼즐에서 "규칙을 이해하면 풀린다"는 깨달음 구조만 가져오고, 이동은 격자 한 줄 밀기로 한정.
